Open the map

Open-source engine for historical maps

Write the campaign once. Watch it march.

Armies, routes, forts and sources in one JSON file. Histamation turns it into a map you scroll through, with every uncertainty drawn and every claim cited.

Open the map → Read the docs

One file in, one map out

  1. Describe

    Factions, places, troop tracks, events, chapters and the sources behind them.

  2. Check

    The checker catches malformed dates, out-of-order tracks and broken references before a reader does.

  3. Play

    Scroll the story chapter by chapter, or scrub freely through time.

data/campaigns/waterloo-1815.json
{
  "id": "prussian-thielmann",
  "kind": "unit",
  "faction": "prussian-army",
  "track": [
    { "when": "1815-06-16", "at": "sombreffe",
      "strength": 24000, "certainty": "approximate" },
    { "when": "1815-06-17/1815-06-19T12:00", "at": "wavre",
      "strength": 20000 }
  ],
  "sources": ["hofschroer-1999", "wp-wavre"]
}
$ npx histamation-check waterloo-1815.json
0 error(s), 0 warning(s), 0 info
3 factions · 16 places · 7 entities · 16 events · 8 chapters

Uncertainty is drawn

A conjectural position is a circle on the ground, not a confident dot.

Every claim cites

Tracks, events and chapters point to the sources behind them.

Many languages

Any text can carry several translations; readers switch in place.

No backend

Static files only: no server code, no account. The basemap is self-hosted.
