Cara kerjanya: Arsitektur Empat Tahap

Spesifikasi Naskah (Schema Excerpt)

Struktur data memisahkan fakta historis dari bagaimana peta menampilkan animasi, mempertahankan integritas akademis sitasi primer.

type HistoricalTroopTrack 
interface HistoricalTroopTrack {
  entityId: string;            // eg. "diponegoro_squadron"
  path: [number, number][];     // [[lon, lat], ...]
  timestamps: number[];       // Epoch seconds strictly monotonic
  uncertaintyRadiusKm?: number;
  primaryChronicleRef: string;  // eg. "Babad Diponegoro §IV"
}
